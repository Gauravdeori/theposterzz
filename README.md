# 🚀 THEPOSTERZZ Launchpad

A premium, high-performance "Coming Soon" landing page for **THEPOSTERZZ**. Designed for the Gen Z vibe with a focus on elite aesthetics, smooth animations, and functional lead generation.

---

## ✨ Features

- **Premium UI/UX**: World-class design featuring Light/Dark mode, glassmorphism, and high-fidelity layouts.
- **Elite Animations**: Staggered entrance reveals and smooth transitions powered by **Framer Motion**.
- **Functional Lead Gen**: Fully operational email collection form integrated with **Web3Forms**.
- **Brand Integrated**: Official brand-colored buttons for Instagram and Amazon with shimmer effects.
- **Instagram Mini-Browser**: A custom-built, responsive Instagram feed preview with macOS-style UI.
- **Fully Responsive**: Optimized for every screen size, from small mobile phones to 4K displays.
- **Environment Driven**: Secure handling of API keys using Vite environment variables.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [Shadcn/UI](https://ui.shadcn.com/) + [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Forms**: [Web3Forms](https://web3forms.com/)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / yarn / bun

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Gauravdeori/theposterzz.git
   cd theposterzz
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Create a `.env` file in the root directory and add your Web3Forms Access Key:
   ```env
   VITE_WEB3FORMS_ACCESS_KEY=your_key_here
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 📂 Project Structure

- `src/components/`: Core UI components (ComingSoon, etc.)
- `src/assets/`: Images and brand resources.
- `src/hooks/`: Custom React hooks (toast, etc.)
- `src/index.css`: Global styles and custom animations.
